🚌 Bus Pass Management System

📌 Project Overview

The Bus Pass Management System is a Python 3 based console application designed to manage bus passes easily and efficiently.

🎯 Objectives

- Issue new bus passes.
- Renew existing bus passes.
- Search passes by ID.
- View all issued passes.
- Maintain pass records.

✨ Features

- New Pass Issuing
- Pass Renewal
- Pass Search
- View All Passes
- Automatic Pass ID Generation
- 25% Student Discount
- File Handling

💻 Technologies Used

- Python 3
- Lists
- Dictionaries
- Functions
- File Handling

💰 Pass Types and Fees

Pass Type| Validity| Fee
Monthly| 30 Days| Rs. 500
Quarterly| 90 Days| Rs. 1350
Yearly| 365 Days| Rs. 4800

Student Discount: 25%

▶️ How to Run

1. Install Python 3.
2. Download the source code.
3. Open Terminal in the project folder.
4. Run this command:

python bus_pass_management.py
